# Ejercicio 17

- Crear una carpeta con el nombre “Ejercicio_17”
- Abrir la Visual Studio y cargar la carpeta “Ejercicio_17”
- Crear un archivo “index.html”
- Agregar los siguientes elementos, en el orden dado:
    - Elemento “header”, contenido “Soy una página”
    - Elemento “nav”, dentro incluir lo siguiente:
        - Elemento “a”, contenido “Panel”
        - Elemento “a”, contenido “Doctores”
        - Elemento “a”, contenido “Especialidades”
        - Elemento “a”, contenido “Búsqueda de Pacientes”
    - Elemento “main”, dentro incluir lo siguiente:
        - Elemento “div”, contenido “Hola a todos!”
    - Elemento “footer”, contenido “Información de mi empresa”

Abrir la carpeta “Ejercicio_17” y hacer doble click en  “index.html”

Resultado: Debe abrirse un navegador y se debe mostrar el contenido de “index.html”


# Ejercicio 17 - b
Tenemos que relacionar dos páginas.

- Para las etiqueta que es “Panel”, el atributo “href” debe apuntar al archivo “index.html”
- Para las etiqueta que es “Doctors”, el atributo “href” debe apuntar al archivo “doctors.html”
- Crear un segundo archivo en Visual Studio, llamado “doctors.html”.
- Copiar el contenido desde “index.html”
- Cambiar el contenido del elemento “div” y poner “Soy un listado de Doctores”
- En los archivos “index.html” y “doctors.html” deben modificar las etiquetas “a”, agregando el atributo “href”

Resultado: Desde el navegador, si haces click en los enlaces, tienes que navegar desde una página a otra.
